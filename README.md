# FamilyWheel — Семейный персонализированный руль

**Проблема**  
Дети могут случайно «завести» автомобиль, даже когда это опасно.

**Решение**  
**FamilyWheel** — интеллектуальный руль с защитой для детей:  
- адаптируется под каждого ребёнка  
- блокирует поворот при «детском хвате»  
- даёт полную свободу взрослому  
- интегрируется с Speech Editor и Parent Voice

**Главная функция — ChildPressureLock**  
Запоминает индивидуальный порог силы (2–5 кг).  
При «детском хвате» руль полностью блокирует поворот.  
Взрослый снимает блокировку одним касанием телефона или ключю.  
AI отличает «это мой сын» от «это чужой» по отпечатку руки.

**Как это выглядит**
[Родитель]          [Ребёнок пытается завести] |                           | Полный контроль + ключ              Датчик силы нажатия |                           | Блокировка руля                 (stretchable pressure sensor) |                           | [AI FamilyWheel]          Разрешение только по отпечатку / ключу |                           | [Система безопасности]      Блокировка поворот < порога ребёнка |                           | Интеграция с Speech Editor     Идентификация ребёнка |                           | (Parent Voice)          Запоминание предпочтений
**Техническая основа**  
- Stretchable pressure sensors (аналог FORCIOT)  
- AI-модуль для распознавания ребёнка  
- Электромагнитный или механический фиксатор руля

**Преимущества**  
✅ Полная безопасность в машину  
✅ Интегрируется с Speech Editor и Parent Voice  
✅ Уникально в связке с остальными проектами

**Почему это не ново**  
Есть Teen Driver (только лимиты скорости) и патенты с датчиками давления.  
Но нет комбинации: сила + распознавание ребёнка + блокировка поворота + Speech Editor.

**Статус**  
Концепт MVP (прототип на модели руля). Разработка продолжается.
